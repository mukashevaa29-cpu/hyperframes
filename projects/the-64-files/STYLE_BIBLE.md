# The 64 Files: стиль-библия (по 20 роликам, 17.10–17.11.2026)

Источник: 20 вертикальных роликов 576×1024, 30 fps, 36–85 с (в среднем 65 с).
Проанализировано **все 39 174 кадра** (каждый кадр, не выборка). На каждом кадре замерены:
яркость, контраст, точки чёрного и белого (p5/p95), насыщенность, тёплый/холодный сдвиг, оттенок,
резкость, виньетка, глобальное движение камеры (оптический поток → сдвиг/масштаб/поворот).
Плюс детекция склеек, затемнений и вспышек, озвучка по словам (ElevenLabs Scribe) и замеры громкости.
Сырые данные лежат в `reference/`: `shots/*.json` (621 план), `transcripts/*.txt`, `videos.csv`.

## 1. Формат

| Параметр     | Значение                                                                                                                |
| ------------ | ----------------------------------------------------------------------------------------------------------------------- |
| Кадр         | 9:16. Рендер в 1080×1920, у исходников 576×1024                                                                         |
| FPS          | 30                                                                                                                      |
| Длина        | 55–80 с, цель **~65 с**. Короче 50 с только у «what if» роликов                                                         |
| Конец        | 4–9 чёрных кадров в самом конце, ~0.2–0.3 с, с тонкой световой полоской-бликом по центру                                |
| Водяной знак | `@the64files` + «IF YOU SEE THIS ON YOUTUBE, IT'S STOLEN» (появился в ноябре), полупрозрачный, по центру над субтитрами |

## 2. Сценарий и ритм речи

- **Хук ≤ 4 с**: шокирующее утверждение + крючок удержания.
  Шаблоны: «This man … and that's not even the scariest part» / «Wait till you see…» /
  «Stay until number one» / «It's not who you think».
- Сразу следом **имя + титул** («Mikhail Tal, the Magician from Riga.»). Даты и места даются
  отдельной короткой фразой: «New York, December 2024.» / «Bled, 1965.»
- Короткие предложения по 2–8 слов, много фрагментов. **131–166 слов/мин (медиана ~150)**.
- Паузы между словами по медиане 60–80 мс: озвучка плотно смонтирована, без «воздуха».
  Пауз > 0.4 с всего 4–20 на ролик, только на драматических битах.
- Структура: хук → кто это → предыстория (возраст/год/город) → эскалация с цифрами → твист →
  точка-эмоция → **CTA-вопрос с числом**: «Comment a number» / «Rate him 1 to 10» /
  «How many … would you last?» / «Follow for more».
- Последняя фраза часто возвращает к хуку («Not bad for a kid who was supposed to herd goats.»).
- Рекламные вставки (Chessnut, Chessigma) идут в самом конце, перед CTA: 5–10 с плюс «Link in bio».

## 3. Монтаж

| Метрика (621 план)            | Значение                                                                                                |
| ----------------------------- | ------------------------------------------------------------------------------------------------------- |
| Средняя длина плана           | **2.09 с**, медиана **1.8 с**                                                                           |
| Доля планов 1–3 с             | 57 %                                                                                                    |
| Планы > 4 с                   | 8.5 % (только «дышащие» планы: графики, финал)                                                          |
| Вспомогательные планы < 0.3 с | ~10 % (вспышки, хлёсткие кадры)                                                                         |
| Тренд                         | Со временем монтаж ускоряется: в октябре медиана 2.1–3.3 с, в ноябре 1.17–1.75 с, 48–55 планов на ролик |

- **Склейка по слову**: смена плана почти всегда приходится на начало новой фразы или ключевого слова.
- Новый план на каждый новый факт, имя, число или локацию.

### Типы переходов (по разбору покадровых полос вокруг склеек)

1. **Хлёст с размытием + фокус-пулл** (основной, ~60 %). Кадр 0 нового плана сдвинут по горизонтали
   и сильно размыт по направлению движения. Следующие 1–2 кадра доезжают на место, дальше
   размытие гаусса уходит за **4–6 кадров** (≈0.15–0.2 с). Одновременно идёт лёгкий наезд.
   Аналоги в реестре: `whip-pan-cut` + `focus-blur-resolve` / `focus-rack`.
2. **Вспышка в белое (bloom)**. Кадр 0 почти белый, за 4–6 кадров «проявляется» тёплый пересвеченный
   новый план. Ставится на эмоциональных битах («Hikaru won **once**.», «Meet Witty Alien»).
   В реестре: блок `flash-through-white`, плюс `seam-craft` против белых провалов.
3. **Прямая склейка на удар** с тряской камеры 2–4 кадра (CHECKMATE, «ZERO», штампы).
   В реестре: `camera-shake`, `headline-slam`, `shutter-slam`.
4. **Падающий предмет**: газета, документ или телефон влетает с поворотом и размытием в движении
   и садится за ~8 кадров. В реестре: `velocity-throw-snap`, `motion-blur`.
5. **Разделённый экран / VS-плашки** со сдвигом по диагонали (аниме-парафраз «domain expansion»).

## 4. Камера (оптический поток по каждому кадру)

- Камера **никогда не стоит**: статичных планов почти нет (0–10 на ролик).
- **Медленный наезд** в 369 планах из 621 (59 %): медиана +12.7 % за план, ≈ **+6.6 % в секунду**.
- **Отъезд** в 119 планах (19 %): медиана −22 %. Используется для «раскрытия» (зал, стадион, карта)
  и в финальном CTA-плане.
- **Дрейф вбок** почти всегда идёт вместе с наездом: медиана 33 px/с, p75 75 px/с (в масштабе 576 px).
- **Крен (roll)** ±2–5° на динамичных досках и падающих предметах.
- **Тряска** на ударных словах: короткая, 0.1–0.6 с.
- Ощущение 2.5D: плоские персонажи стоят в псевдо-3D сценах (доска в перспективе на переднем плане,
  размытый передний план из фигур, задник). Глубина собирается слоями с параллаксом.

## 5. Свет, контраст, цвет

|                      | Октябрь (тёмная эпоха) | Ноябрь (светлая эпоха) |
| -------------------- | ---------------------- | ---------------------- |
| Средняя яркость Y    | 48–77                  | 77–114                 |
| Контраст (σ яркости) | 44–58                  | 47–70                  |
| Насыщенность         | 89–135                 | 90–124                 |

- **Свет «театральный»**: прожекторы сверху (лучи-конусы, god rays), тёплый ореол за головой
  персонажа, глубокая виньетка, низ кадра темнее верха. Чёрная точка не уходит в 0: тени приподняты,
  мягкий «плёночный» вид.
- **Цвет кодирует локацию**: каждая история живёт в 1–3 палитрах.
  - Синий/фиолетовый со светом прожекторов: стримы, онлайн, Hikaru, Witty Alien.
  - Тёплый красно-коричневый: турнирные залы, СССР, классика (Tal, Najdorf).
  - Зелёный «библиотечный»: Levy / GM Hunter, архивы.
  - Солнечный оранжево-красный: Fan God, Индонезия.
  - Светлая комната с окном и зелёной лужайкой: ноябрьский базовый сет (Hikaru vs Magnus).
- Средний цветовой сдвиг лёгкий тёплый (b\* +2…+5), в «онлайн»-эпизодах уходит в холод (−7).
- **Боке и частицы**: пыль в лучах, конфетти на победах, размытые огни на заднем плане.
- **Тени**: мягкие, без контура. Падающая тень персонажа на стол или доску плюс контактная тень
  у фигур.

## 6. Персонажи и ассеты

- **Плоские 2D-персонажи**: крупная голова (≈45 % высоты тела), простые формы, тонкая обводка
  чуть темнее заливки, румянец, большие глаза с бликом. Узнаваемость держится на 1–2 чертах
  (кудри Магнуса, чёлка Хикару, очки и бородка Леви, наушники Witty Alien).
- Эмоции читаются по бровям и рту, плюс «капля пота» как эмодзи-деталь.
- Анимация лица: моргание, смена эмоции на ключевое слово, лёгкое покачивание.
- **Реальные фото** игроков (ч/б или цветные) вставлены как «знакомство»: имя сверху **серифной
  капителью** («HIKARU NAKAMURA»), под ним мелко должность и кредит «Photo: … CC BY-SA».
  1–3 фото на ролик.
- **3D-доска**: зелёно-белая (chess.com) или тёмная, фигуры белые и тёмно-серые, подсветка хода
  (зелёная или красная клетка), значки `!!` (бирюзовый круг), `??`, линии атаки.
- Инфографика: огромные цифры (рейтинг, счёт, «2.13 SECONDS»), шахматные часы, бары, карты из
  точек, газеты, календари, твиты и посты.

## 7. Текст

- **Субтитры**: 1 строка, 2–5 слов, по центру, на **y ≈ 64–67 % высоты**. Белый жирный округлый
  гротеск (похоже на Nunito Black / Rubik Bold), тонкая тёмная обводка плюс мягкая тень.
  Слово подсвечивается **по одному в такт речи** (караоке) акцентным цветом: жёлто-зелёный
  `#B8F23A`, жёлтый `#FFC83A`, красный `#FF4D4D` (опасность, проигрыш), голубой `#5AB8FF` (имена).
  Подложки нет.
- **Заголовок-хук** (первые 1–3 с): сверху, 2 строки, белое плюс жёлтое, жирный гротеск
  капслоком с тенью.
- **Плашки-ярлыки** («BLINDFOLDED», «WORLD RECORD», «NOT ON THE MENU», «PANIC»): прямоугольник
  с лёгким наклоном, жёлтый/красный/бирюзовый фон, тёмный капс. Появляются pop-ом (скейл 0→1.1→1
  за ~6 кадров).
- **Штампы** («QUIT», «BANNED», «WITHDRAWN», «ZERO»): красная рамка, наклон −8°, слэм с тряской.
- **Большие числа**: верх кадра, огромный жирный шрифт, под ним маленькая цветная подпись
  («GAMES AT ONCE»). Часто идут каунт-апом.
- **Место и дата**: маленький разрядкой капс по центру сверху: «ARLINGTON, TEXAS · OCT 2025».
- **CTA-карточка** в финале: вопрос в жёлтой плашке плюс «COMMENT A NUMBER» плюс
  «FOLLOW THE 64 FILES».

## 9. Лучшие ролики (референсы для новых)

Отбор по полировке, разнообразию переходов, читаемости света и плотности монтажа:

1. **20261117 — Hikaru на детекторе лжи.** Самый зрелый: 48 планов, светлый базовый сет, все
   5 типов переходов, сильная арка и финал.
2. **20261111 — «2.13 seconds» (Hikaru).** Лучшая инфографика (рейтинг 3500, паттерны), чистый свет.
3. **20261103 — Fan God.** Самая цельная палитра (закатный оранжевый), хорошие посты и соцсети.
4. **20261104 — GM Hunter (Levy).** Сильная локация-метафора (коридор из досок), уверенная камера.
5. **20261030 — Double Bongcloud.** Лучшая доска и подсветка ходов, хороший ритм.

Осторожно: **20261114** (Witty round 2) пародирует персонажей Jujutsu Kaisen (Годжо, Сукуна,
«Domain Expansion»). Выглядит эффектно, но это чужие узнаваемые персонажи, такое не тиражировать.
