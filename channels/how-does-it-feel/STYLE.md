# «How does it feel?» — библия стиля канала

Источник: покадровый разбор 4 референсов (Хиросима, электрический стул, медный бык, костёр;
7 618 кадров при 30 к/с). Подробные отчёты — `../ref/v1..v4/report.md`.
Правило канала: **рекламных вставок нет** (ни бейджа, ни карточки).
Цель: та же грамматика, что у референсов, но лучше — без мёртвых пауз, с живой камерой, звуком на каждом действии и петлёй.

## 1. Формат

- 1080×1920, 30 к/с, 50–70 с, английский, второе лицо («you»).
- Формула: **холодное открытие кульминацией (1–1.5 с без титра) → вопрос «HOW DOES IT FEEL…?» → место/время → процедура → эскалация цифрами → тело отказывает → глаз закрывается → «And then… comes darkness.» → плоская линия → чёрное.**
- Подпись канала в финале — всегда фраза «And then… comes darkness.» и красная линия кардиомонитора с писком 1 кГц.

## 2. Палитра (измерено)

| Роль                              | Hex                                                                                       |
| --------------------------------- | ----------------------------------------------------------------------------------------- |
| Фон                               | `#010101`, верхние 50 % кадра всегда чёрные                                               |
| Зарево пола (норма)               | radial из `50% 104%`: `#861207 → #4A0901 → #1A0200 → прозрачно` к ~55 % высоты            |

| Неон-линия                        | ореол `#FF3B36` (размытие 9–22 px), тело `#FB2945`, сердцевина `#F2EEEA`/`#FFE5E7` 4–5 px |
| Заливка объектов                  | `#0C0A0C` → нагрев `#450B09` → раскалено `#871712`                                        |
| Титр белый / красный              | `#F5F5F5` / `#F54341`                                                                     |

Освещение: один источник — зарево снизу по центру; объекты светятся сами; теней нет. Зарево = термометр сюжета (разгорается на жаре, гаснет по ступеням в последние 10 с, в ноль на «darkness»).

## 3. Рисунок

- Плоский 2D-вектор, равная толщина линии, скруглённые стыки. Одна центрированная пиктограмма на предложение, 45–85 % ширины.
- Трёхслойный неон: размытый красный ореол → сплошная заливка (гасит свечение внутри) → тонкая белая сердцевина.
- Персонаж «ты»: чёрный манекен с белыми рентгеновскими костями (дуги рёбер, позвоночник из точек, таз из двух кругов), овальная голова, красные глаза. Внутри объектов — красный «рентген».
- Инфографика-врезки: огромные красные неоновые цифры (Roboto Condensed 700–900) + крошечная серая подпись единиц + кольцо прогресса/шкала.

## 4. Камера и движение

- Каждый новый план «приземляется»: `scale 0.89 → 1` за 5 кадров, `power2.out` (только обёртка сцены, не титры).
- Панч-склейки: тот же рисунок ×0.8–×2.3.
- **Улучшение:** на всех удержаниях — медленный дрейф `+1.5 %/с` (в референсах 3–5 с полной статики — главный минус).
- Одно действие на сцену, приземляется на ударное слово (0–5 кадров до слова): прорисовка линии 4–10 к, рост с овершутом 4+5 к (`back.out(2)`), счётчики `expo.out`, медленные превращения линейно 20–40 к.
- Вспышки как пунктуация: `#FDF3E8` 0.9 → 0 `expo.out` за 0.25–0.9 с; ~5 на ролик. Тряска — только на взрывах (±5 px, по сиду).
- Фоновая жизнь всегда: угли поднимаются 1–2 px/к, огонь мерцает каждые 2 к, дым дрейфует — всё от сида и времени таймлайна.
- **Улучшение:** плавная анимация персонажа (суставы через transform-origin), а не смена поз.

## 5. Склейки и ритм

- Только жёсткие склейки, за 1–4 к (медиана 2) до начала фразы. Новая мысль = новая картинка.
- План 1.1–3.5 с (медиана ~2 с), 4–5 склеек на 10 с. Якорные планы (герой в огне, глаз) возвращаются, каждый раз на худшей стадии.
- Повторяющиеся инфографики эскалируют на втором проходе (вольтметр 1000 → 2000).

## 6. Титры

- Одна строка по центру, центр на **y = 248 px** (12.9 % высоты), Roboto Condensed 700, 75 px, CAPS, трекинг +1 %.
- 1–3 слова, ≤17 символов, ~0.9 с, без пустых промежутков после первого титра; появление за 0–3 к до слова.
- Красный: финальный кусок каждого предложения (однословный — целиком красный, иначе только слово-итог) + ключевые существительные, цифры, места. ~25–30 % слов.
- **Улучшение:** микро-«впрыгивание» `scale 1.08 → 1` за 3 к + тонкая тень `0 2px 8px #000` для читаемости поверх ярких сцен.

## 7. Звук

- Голос: ~130 слов/мин, низкий мужской, спокойно-драматичный. Громкость итог −14 LUFS (шортсы), голос сверху, музыка-дрон на −15 дБ под голосом.
- Свуш или саб-удар на **каждой** склейке; SFX на каждом видимом действии (тик таймера, треск огня, писк монитора, удар на вспышке).
- Холодное открытие: громкий дрон/крик/треск без титра 1–1.5 с. Финал: писк флэтлайна 1 кГц → тишина.

## 8. Улучшения против референсов (обязательно)

1. Первый кадр = готовое превью (герой + свечение), никогда не белый/чёрный.
2. Нет удержаний без движения дольше 0.5 с.
3. Зерно 2–3 % поверх всего (убирает бэндинг градиентов).
4. Подписи-лейблы в диаграммах ≥ 28 px (читаемы на телефоне).
5. Петля: последний кадр (линия на чёрном) склеивается с первым.
6. Без рекламы.
